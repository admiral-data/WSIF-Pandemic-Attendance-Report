# WSIF Attendance Analysis (2017–2024)

This project examines statewide student attendance trends in Washington public schools using data from the Washington School Improvement Framework (WSIF), published by OSPI.

The analysis focuses on post-pandemic differences between middle and high schools.

## Key Finding
Attendance declined following the COVID-19 pandemic across all school levels, with high schools showing a steeper decline and weaker recovery than middle schools.
